## Panel-specific overlay

The transformed design is a contemporary editorial poster in a playful independent-magazine voice, printed like Risograph or screen print. Use a few spot colours from the source, translucent overprints, visible halftone, slight misregistration, ink bleed and a little xerographic noise. Asymmetric layout, large negative space, the subject cropped or partial, one visual centre. Type is a main compositional element: wide rounded contemporary grotesk, allowed to be nearly graphic in scale, overlapping the image, with tiny secondary notes. Warm off-white uncoated paper. Imperfection stays controlled. It is not a tidy brand template, a photographic filter, a complex collage, a digital gradient or a fluorescent screen glow.

These overlay rules add to `references/soldier-runtime.md`. They never replace the source brief or the family runtime contract.

Write every selected final PNG directly inside one fresh task directory under `~/Desktop/xxd/xxd-panel-239/` (or the explicit `--out` root). Use collision-safe filenames; do not create source, mode, or size subdirectories and do not generate an automatic contact sheet.
